# 🛒 DjangoMart — интернет-магазин на Django

Дипломный проект интернет-магазина: каталог товаров по категориям, регистрация и вход, корзина, избранное, поиск и отзывы к товарам.

## ✨ Возможности

- 👤 **Аккаунт** — регистрация, вход/выход, профиль с аватаром и телефоном
- 📦 **Каталог** — категории и товары, фильтры (цена, наличие, скидка, новинка)
- 🔍 **Поиск** — по названию, описанию и категории, с поддержкой кириллицы и транслитерации
- 🛒 **Корзина** — добавление, изменение количества, удаление (только для авторизованных)
- ⭐ **Отзывы** — оценка 1–5 и комментарий к товару
- ❤️ **Избранное** — добавление/удаление товаров, отдельная страница
- ⚙️ **Админ-панель** — управление категориями, товарами, отзывами, корзинами и заказами

## 🧱 Технологии

- Python 3 + Django 5.2
- SQLite
- django-filter
- Bootstrap (шаблоны в `base_template/`)

## 🚀 Запуск проекта

1. **Перейдите в папку проекта**
   ```bash
   cd Ara_django_shop
   ```

2. **Создайте и активируйте виртуальное окружение**
   ```bash
   python -m venv venv

   # Windows
   venv\Scripts\activate

   # macOS / Linux
   source venv/bin/activate
   ```

3. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

4. **Примените миграции**
   ```bash
   python manage.py migrate
   ```

5. **(Опционально) Заполните базу тестовыми данными**

   В проекте есть готовый скрипт с категориями, товарами и суперпользователем (`admin` / `admin123`):
   ```bash
   python manage.py shell < seed_data.py
   ```

   Либо создайте суперпользователя вручную:
   ```bash
   python manage.py createsuperuser
   ```

6. **Запустите сервер разработки**
   ```bash
   python manage.py runserver
   ```

7. **Откройте в браузере**
   - Магазин: http://127.0.0.1:8000/
   - Админ-панель: http://127.0.0.1:8000/admin/

## 📁 Структура проекта

```
Ara_django_shop/
├── core/            # настройки проекта, корневые urls
├── accounts/        # пользователи, регистрация, вход, профиль
├── products/         # категории, товары, отзывы, избранное, поиск, фильтры
├── orders/           # корзина и заказы
├── base_template/   # HTML-шаблоны
├── media/            # загружаемые изображения (товары, аватары)
├── staticfiles/       # статика (CSS)
├── seed_data.py       # скрипт наполнения БД тестовыми данными
└── manage.py
```

## 🗺️ Основные маршруты

| Раздел          | URL                              |
|-----------------|-----------------------------------|
| Главная         | `/`                                |
| Категория       | `/products/category/<slug>/`      |
| Товар           | `/products/product/<slug>/`       |
| Поиск           | `/products/search/?q=...`         |
| Избранное       | `/products/wishlist/`             |
| Корзина         | `/orders/cart/`                   |
| Вход            | `/accounts/login/`                |
| Регистрация     | `/accounts/register/`             |
| Профиль         | `/accounts/profile`               |
| Админ-панель    | `/admin/`                         |

## ✅ Результат проверки

Код проекта проверен: модели, представления, формы, маршруты и шаблоны согласованы между собой (все `{% url %}` в шаблонах соответствуют зарегистрированным маршрутам), все формы содержат CSRF-токен, доступ к корзине, избранному и отзывам защищён `@login_required`. Функциональность полностью покрывает требования технического задания.
